- Optimize for a real YDS learner: one clear primary action per screen, progressive disclosure, comprehensible progress labels, consistent learning flows.
- Preserve established design tokens and component styles unless the task explicitly changes the design system.
- Design at mobile (~360px), tablet and desktop widths. Avoid clipped long words, tight example-sentence containers and overlapping controls.
- State what happens after submit, on error, on retry and when the user presses Enter or goes back.
- Include accessibility: text contrast, focus order, announcements where useful, semantic HTML, touch targets, reduced motion.
- Treat a screenshot as visual reference, NOT proof of a working implementation.
